## 📌 TL;DR（执行摘要）

1. **供给假设（假设1）：已验证通过，且远超预期。** 上海不是"活动不够"，是"活动多到看不完"——全市每年约 **23.6 万场**公共文化活动、**220 家**社区文化活动中心 + **6608 个**居村活动室、老年教育全年 **1.3 万门课 / 105 万个学额**。供给不是问题。
2. **但产品定位必须改。** 上海已有强势在位者 **「文化云」（原"文化上海云"，上海创图网络科技运营）**，聚合 **22 万场活动 / 5500 家场馆 / 3000 个社团**，注册用户 500 万+，且**已在做适老化**（官方描述："操作更简单，关键信息大字，看得清"）。在上海再做"又一个活动聚合器"= 正面撞政务数据独占的墙。
3. **真正的空白被我找到了，而且是官方数据坐实的**：上海市民艺术夜校 2025 秋季班 **95 万人同时在线抢课、最热课 3 秒清空**；首开的中老年班（56-70 岁）50 门课**拟招 1300 人，实际仅 600 名中老年成功报名**——官方归因："**老年人对线上操作不熟练**，中老年班抢课速度相对较慢；当天咨询电话大都是老年人打来的，询问如何报名。"
   → **老同志不是不想参与，是抢不到、不会抢。** 这是 old-buddy 的尖刀。
4. **定位建议从"聚合器"改为"退休生活助理"**：文化云是**货架**，old-buddy 是**帮你挑 + 提醒你抢 + 教你报 + 陪你去**的那一层。
5. **试点选型**：主试点 **虹口区曲阳路街道**（本地活力退休族，验证核心闭环）；副试点 **闵行区古美路街道**（老漂随迁族，验证扩展性）。

## 2. 🔥 关键发现：抢课/报名黑洞（最强需求信号）

这是本轮调研最有价值的产出，全部为官方或权威媒体披露的硬数据：

| 时间 | 事件 | 数据 |
|---|---|---|
| 2025 秋季班 | 上海市民艺术夜校报名 | 2300 门课，**最高峰近 95 万人同时在线抢课**；最热门课 **3 秒**告罄，5 秒内 8 门课抢完，1 分钟 143 门课被秒 |
| 2025 春季班 | 同上 | **117 万人**瞬时在线抢课；1651 门课中 **879 门**被一抢而空；古琴课 3 秒爆满 |
| 2026 春季班 | 同上 | 报名开放 **10 分钟内 569 门课报满**（占全部课程 22.8%） |
| 2025 春季 | **首开中老年班（56-70 岁）** | 16 个分校推出 50 门线下课，**拟招 1300 人 → 实际仅 600 名中老年成功报名** |

**官方归因（原文）**：
> "由于老年人对线上操作不熟练，今年面向 55-70 岁人群首次开设的中老年班抢课速度相对较慢。当天，市群艺馆接到的夜校咨询电话**大都是老年人打来的，询问如何报名**。"

**另一条被官方点名的结构性缺口**：
> "原本夜校学员的参与范围在 18-55 岁，但近年来许多**临近退休的职工**不断反映，他们的年龄超过夜校报名范畴，而**老年大学一般在白天开班又无法参与**，退休前想充电却苦于无门。"
> —— 这就是 **56-60 岁"两不靠"人群**，正是 old-buddy 的核心靶心。

**人大/参事层面的判断（印证我们的人群选择）**：
> "学员群体从'传统老人'转向'**活力老人**'，**50 后、60 后高学历、高消费能力的群体逐渐成为主力军**……需求从传统的唱歌、跳舞、画画等兴趣娱乐**升级为自我价值的实现**，对理财、文化、健康和数字技能等实用型课程的需求激增。"
> "**热门课程'秒光'与基础课程闲置并存**，折射出供需错配问题日益突出。"

### 产品含义（这一条最重要）

需求侧的真实痛点链条是：

```
想参加（意愿极强，95 万人抢课）
  → 不知道什么时候开抢（信息不对称）
  → 抢的时候手速慢/不会操作（数字鸿沟）
  → 抢不到（3 秒清空）
  → 放弃 / 打电话问工作人员（官方证实）
```

**old-buddy 的第一个杀手功能不是"聚合活动列表"，而是「开抢日历 + 定时提醒 + 报名代劳/图文指引 + 捡漏通知」。**
这是文化云、夜校官方系统、老年大学**都不做也不便做**的一层（它们是供给方，不能帮用户"抢自己的名额"）。

## 3. ⚠️ 竞品格局修正：上海存在强势在位者

| 项目 | 文化云（原"文化上海云"） |
|---|---|
| 运营方 | 上海创图网络科技发展有限公司（沪ICP备07032795号） |
| 定位 | 全国**第一个**省级区域全覆盖的公共文化数字化服务平台（政府主导建设） |
| 活动体量 | **22 万场**文化活动 |
| 场馆 | **5500+ 家**（覆盖市/区/街镇三级） |
| 社团 | **3000+ 个** |
| 用户 | 注册 **500 万+**，日均浏览 50 万人次 |
| 功能 | 活动预约、场馆预订、社团风采、竞赛互动、艺术鉴赏、艺术培训、云直播 |
| 适老化 | **已做** — 官方描述："提升中老年用户体验：操作更简单，关键信息大字，看得清" |
| 形态 | App（v5.1.4，2026-08 仍在更新）+ 网站 + 微信公众号 |

### 战略判断

**不能做的**：在上海做"又一个本地活动聚合器"。文化云有政府数据独占权、场馆直连、500 万存量用户，且已经在做大字适老化。正面撞它 = 必输。

**它做不到 / 不愿做的（我们的空间）**：

| 缺口 | 文化云为何做不了 | old-buddy 的机会 |
|---|---|---|
| 帮用户**抢**名额 | 它是供给方/官方平台，不能帮个人抢公共资源 | 开抢日历 + 提醒 + 代劳指引 + 捡漏 |
| **跨系统**聚合 | 只有公共文化活动，不含商业演出、社区自组织、老年大学、体育、志愿、邻里局 | 全口径"退休生活可做之事" |
| **社交/结伴** | 工具型（查+订），无"陪你一起去" | 因活动而认识人（PRD 方向 B） |
| 按**带孙时间窗**组织 | 全龄平台，不为"孙辈上学窗口"设计 | 8:30-11:30 / 14:00-16:00 时段化推荐 |
| **老漂融入** | 无地域来源/方言/同乡维度 | 老漂邻里（PRD R7） |
| **主动提醒** | 用户需自己打开找 | 微信服务通知推送 |

**一句话**：**文化云是货架，old-buddy 是导购 + 闹钟 + 同行的人。**

> 💡 附带机会：文化云的运营方是市场化公司（创图科技），未来存在**数据合作/API 对接**可能，而非只能当对手。M1 阶段值得接触。

## 4. 人群分层修正（PRD 需修正）

原 PRD 把"本地退休族"和"老漂族"混在同一个 MVP 里（用户故事 2「张叔·老漂」被放进了 MVP）。上海数据显示这**两类人差异极大，必须分阶段**：

| 维度 | 层1：本地活力退休族 | 层2：老漂随迁族 |
|---|---|---|
| 规模（上海） | 户籍 60+ **577.62 万**（37.6%）；60-69 岁占 60+ 的 **58.7%**（341.4 万） | 外来 60+ 流动人口约 **65 万**，其中老漂约 **32 万** |
| 户籍/来源 | 上海户籍 | 主要来自安徽、江苏、浙江；平均来沪 **3.6 年** |
| 年龄 | 50-65（我们的靶心是 **56-60 "两不靠"**） | 60-70 为主（超九成因照顾第三代来沪） |
| 数字素养 | **较高**，会微信/小程序，能自己抢课（只是手速慢） | **低** — 闵行颛桥镇调研：**20%+ 未受任何教育、近 50% 小学文化** |
| 消费力 | **强** — 浦东老龄群体月均支出 **4200 元**，年支出 3-5 万+ 占 48.37% | **弱** — 除养老金外收入近零，且不愿向子女要钱 |
| 核心痛点 | 抢不到好课 / 不知道哪有好玩的 / 想自我实现 | 语言不通 / 社交断裂 / **56.3% 对新环境不熟悉宁可待室内** / 生活半径"家—菜场—学校"三点一线 |
| 获客方式 | **线上可自增长**（抢课刚需强，口碑传播） | **必须靠线下**（居委/社工/志愿者/老漂驿站带） |
| 建议阶段 | **MVP（M1-M2）主打** | **M3+**，且需线下运营配套 |

**修正结论**：MVP 只服务层1。层2（老漂）不是不做，而是**它需要的是"有人带着去"这种线下重运营**，线上产品单独上不去。上海已有成熟抓手可借力：**松江方松街道上泰绅苑"老漂驿站"（2019）、浦东金杨新村街道东方知音苑"老漂驿站"（2017）** —— M3 时优先与这类点位合作，而非自建。

### 5.1 选型矩阵

| 候选 | 目标人群密度 | 供给密度 | 地理紧凑 | 老漂浓度 | 综合 |
|---|---|---|---|---|---|
| **虹口区（曲阳路/嘉兴路街道）** | ★★★ 户籍老龄化 **45.2%（全市第一）**；常住 33.2%（第二） | ★★★ 两街道均为市级"示范中心" | ★★★ 全区仅 23.5 km²，步行可达 | ★ 低 | **★★★ 主试点** |
| **闵行区（古美路街道/虹桥镇）** | ★★★ 常住 60+ **53.64 万（全市第二）** | ★★★ 示范中心；**闵行夜校教学点全市最多（11 街道全覆盖）** | ★★ 面积大 | ★★★ 老漂高地（颛桥镇随迁老人研究地） | **★★★ 副试点** |
| 黄浦区 | ★★★ 户籍老龄化 44.0%（第二） | ★★★ 三个示范中心 | ★★★ 紧凑 | ★ 低 | ★★ 备选 |
| 浦东新区 | ★★★ 常住 60+ **122.89 万（全市第一）**；月均支出 4200 元 | ★★★ 11 个示范中心 | ★ 太大（1210 km²） | ★★ 中 | ★★ 二期扩张首选 |
| 杨浦区 | ★★★ 常住老龄化 31.8%（第三） | ★★★ 四个示范中心 | ★★ 中 | ★★ 中 | ★★ 备选 |
| 崇明区 | ★★★ 43.9% | ★★ 资源在下沉中 | ✗ 远郊分散 | ✗ 低 | ✗ 不选 |

### 5.2 推荐方案

**主试点：虹口区 曲阳路街道**（备选：嘉兴路街道）
- **理由1**：虹口户籍 60+ 占比 **45.2%，全市第一**；常住老龄化 33.2%，全市第二 —— 人群密度天花板。
- **理由2**：曲阳路街道社区文化活动中心是市级 **64 个"示范中心"之一**，供给稳定、有运营能力配合。
- **理由3**：曲阳是典型 80 年代大型工人新村住区，老公房连片、**熟人社会残留强**（有利于"结伴"这类社交功能冷启动）。
- **理由4**：虹口全区仅 23.5 km²，**老同志步行/骑行即可达**——这是关键，老人不跨区参加活动。
- **理由5**：中心城区抢课热度远超郊区（官方数据："受点位分布、交通路线影响，中心城区抢课热度远超郊区"）→ 尖刀功能需求最集中。

**副试点：闵行区 古美路街道**（备选：虹桥镇 / 梅陇镇）
- **理由1**：闵行常住 60+ 53.64 万，全市第二；且是**老漂集中区**（学界对上海随迁老人的实证研究就在闵行颛桥镇做的）。
- **理由2**：**闵行夜校教学点全市最多**，11 个街道全覆盖 → 抢课需求最密。
- **理由3**：古美路街道为示范中心，且是老公房 + 商品房混合的大型居住区，**本地退休族与老漂族同时存在** → 一个街道能同时验证层1和层2。

**执行顺序**：先虹口曲阳（2 周，验证核心闭环）→ 再闵行古美（验证跨区复制 + 老漂场景）。

## 7. 🔧 对 PRD 的三条修正（请审定）

### 修正 1 · 产品定位（**改动最大，优先审定**）

| 编号 | 需求 | 优先级 | 验收标准 | 估算 |
