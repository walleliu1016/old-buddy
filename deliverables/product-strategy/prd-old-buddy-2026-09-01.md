## 📌 TL;DR（执行摘要）
- **做什么**：old-buddy = 城市退休"老同志"的「下周本地好玩清单 + 附近老友局」。方向 A（社区活动周历·发现）为获客楔子，方向 B（老友同好局·轻社交）为留存引擎。
- **为什么现在做**：目标人群（50-60 岁城市带孙退休族）有智能手机、有闲、有强情感痛点；社区活动供给充足但"看不见"；竞品在"本地活动聚合+活动锚定社交"上仍空白。
- **MVP 形态**：**微信小程序**（降低下载门槛），大字号周历 Feed + 一键报名/导航 + 轻量同好约局。
- **下一步**：先选 1-2 个试点城区做供给可行性验证 + 5-8 人用户访谈。

## 1. 产品目标（3 个清晰、正交的目标）
1. **让"附近有什么好玩"一眼可见**（信息差）：把分散在公告栏/街道公众号/微信群/老年大学的社区活动，按地区聚合成未来 7 天可刷的清单。
2. **让"一个人去"变成"有人一起去"**（孤独感）：以活动为锚点，连接附近同龄同好，形成 发现→报名→到场→加好友→再约 的轻社交闭环。
3. **让退休生活从"被需要（带孙）"扩展到"被充实"**（价值感）：在不增加子女负担的前提下，帮老同志重建自己的社会网络与时间意义。

## 2. 用户故事（4 个场景）
- **王姨（57 岁，带孙女上小学）**：早上刷 old-buddy，看到社区书法班周三开课、离家 800 米，一键报名，顺路带孙女去，认识了同小区李叔。
- **张叔（60 岁，县城来帮儿子带娃的"老漂"）**：在"老漂邻里"找到同小区老乡的太极晨练局，不再每天闷在儿女家；第一次有人约他"下周一起去公园拍荷花"。
- **陈姐（55 岁，独居带外孙）**：设置"文艺+公益"偏好后，每周收到"本周精选"，挑了社区合唱团招新，从观众变成队员。
- **子女小刘（帮父母装好小程序）**：开启"远程帮看"，远程帮不识字的父亲报名、查导航，父亲只点"大按钮"即可。

## 3. 用户研究洞察（瑞思）
- **人群切片极优**：50-60 岁"新老人"教育水平、资产、数字素养均高于上一代；银发网民 2025 月活 3.51 亿、月人均 135 小时，且"错峰活跃"（下午最闲）——正好对应孙辈上学后的空档。
- **三重痛点叠加**：① 白天空虚（带娃间隙大段空余）；② 孤独（随迁"老漂族"近 1800 万、43% 为带娃进城；"人生地不熟、想搭句话都难"）；③ 自我价值感弱（退休后身份真空、带娃焦虑）。
- **行为特征**：重度内容消费、轻内容生产（短视频/资讯粘性最高）；怕麻烦子女、怕诈骗、怕复杂操作。
- **洞察**：他们要的不是"再学一个 App 去发动态"，而是"有人告诉我附近有啥、还能有人一起"——**被动接收 + 低门槛参与**才是正解。

## 4. 竞品对比（竞析，7 个对象）

| 维度 | old-buddy（我方） | 闲趣岛 | 糖豆 | 政府智慧社区（雁城/崃生活等） | 志愿汇 | 时间银行 |
|------|------|------|------|------|------|------|
| 本地社区活动聚合（周历） | ★★★ 核心 | ★ 偏交友 | ★ 偏舞友 | ★★ 有但城市割裂 | ★ 仅志愿 | ★ 志愿为主 |
| 同好轻社交 / 约局 | ★★★ 活动锚定 | ★★★ 含相亲 | ★★ 舞友群 | ★ 弱 | ★ 弱 | ★★ 互助 |
| 适老化极致（大字/语音） | ★★★ | ★★ | ★★ | ★★ | ★★ | ★★ |
| 老漂 / 新城市融入 | ★★★ 子模块 | ★ 弱 | 弱 | 弱 | 弱 | 弱 |
| 安全（无婚恋陷阱） | ★★★ 不含相亲 | △ 含相亲风险 | ★★★ | ★★★ | ★★★ | ★★★ |
| 内容生产门槛 | 低（只刷） | 高（发动态/直播） | 中 | 低 | 低 | 低 |

**结论**：A 的"跨城聚合下周活动"在消费端空白；B 的"活动锚定轻社交"相对闲趣岛（交友/相亲驱动、门槛高）形成差异化——我们更**安全、更低摩擦、更贴带孙退休族**。

## 5. 数据依据（数析）
- **人口**：2025 年末 60 岁+ 3.23 亿（占 23.0%），全面中度老龄化；每年约 2300 万人迈入 60 岁，50-60 岁是"新老人"主力。
- **互联网**：银发人群月活 3.51 亿（2025.11，同比 +5.8%），月人均时长 135h；短视频（抖音银发 2.14 亿）、微信渗透极高；下午 16 点活跃比例提升（错峰=退休空闲）。
- **供需缺口**：城镇社区文体活动年均超 3.5 万场次、国家老年大学 6.8 万个基层点——**供给足、但老人"看不见"**，信息聚合价值明确。
- **隔代抚养基数**：全国超 2.3 亿祖辈日常带娃，城镇隔代养育 76.8%，日均 6.8-7.2h；孩子上学后白天出现大段空闲——目标场景成立。
- **银发经济**：2025 约 7 万亿 → 2035 约 30 万亿（占 GDP 10%），政策系统性支持（国办 2024 银发经济意见）。

## 7. 信息架构 & 关键流程

**信息架构（MVP）**
```
old-buddy（小程序）
├─ 首页 · 下周好玩（周历 Feed，R1/R2）
│   ├─ 顶部：定位城区 + 兴趣筛选
│   └─ 卡片流：活动卡（时间/地点/类型/费用/报名按钮）
├─ 活动详情 → 一键报名/电话/导航（R3）
├─ 老友局（P1，R6）
│   ├─ 我的兴趣标签
│   ├─ 附近同龄人（仅同城、同好）
│   └─ 约局：发起/加入"下周一起去"
├─ 老漂邻里（P1，R7）
└─ 我的（适老设置/子女远程帮看 R4/R5）
```

**关键流程（用户参与一次活动）**
```
打开小程序 → 自动定位/选城区
→ 刷"下周好玩"Feed → 点感兴趣活动
→ 看详情 → 一键报名（电话/微信接龙）
→ 到点地图导航前往 → 现场扫码签到
→ 在"老友局"认识同去的人 → 发起/加入下次约局
```

## 8. Non-goals（MVP 不做）
- 不做医疗/健康监测（合规重，非本职责）。
- 不做重度 UGC 社区（短视频/图文创作留给抖音/糖豆/美篇）。
- 不碰婚恋相亲（信任与合规风险高；与"因活动认识人"定位冲突）。
- 不自建老年大学课程（只做"发现+报名"聚合）。
- 不做电商交易（首期）。
- 不做独立 App（首期先做微信小程序，降低下载门槛；远期再评估独立 App）。

## 🔧 M0 修正记录（2026-09-01，试点城市确定为上海后）

> 依据：`m0-shanghai-supply-2026-09-01.md`。上海供给盘点后，以下三处**取代**本 PRD 对应内容，请以修正版为准。

### 修正 1 · 产品定位（改动最大）
- **原**（第 11 行 TL;DR）：old-buddy = 「下周本地好玩清单 + 附近老友局」＝**聚合器**。
- **改为**：old-buddy = 城市退休老同志的「**退休生活助理**」——在公共供给之上做 **提醒 · 代劳 · 结伴** 这一层。
- **原因**：上海已有强势在位者 **「文化云」**（原"文化上海云"，上海创图网络科技运营）：**22 万场活动 / 5500 家场馆 / 3000 个社团 / 500 万注册用户**，且**已做适老化**（官方："操作更简单，关键信息大字"）。"聚合"不再是差异化。
- **新定位比喻**：**文化云是货架，old-buddy 是导购 + 闹钟 + 同行的人。**

### 修正 2 · 需求池新增 3 条（R11/R12 提到 P0 最前）

| 编号 | 需求 | 优先级 | 验收标准 | 估算 |
|---|---|---|---|---|
| **R11** | **开抢日历 + 定时提醒** | **P0（置于 R1 之前）** | 汇总夜校/老年大学/热门活动**报名开放时间**；开抢前 24h + 10min 微信服务通知推送 | 1.5 人周 |
| **R12** | **报名助手（图文指引 + 一键直达 + 信息预填）** | **P0** | 每门热门课 3 步图文指引；一键跳官方报名页；预存信息减少手速损失 | 2 人周 |
| **R13** | **捡漏通知（余位 / 补招 / 未成班课程）** | **P1** | 抓取补招公告与"人数不足未开班"课程，推送匹配用户 | 1 人周 |

**需求依据（官方硬数据）**：
- 上海市民艺术夜校 2025 秋季班：2300 门课，**95 万人同时在线抢课**，最热门课 **3 秒**清空，1 分钟 143 门被秒。
- 2025 春季班：**117 万人**抢课，1651 门课中 **879 门**抢空。
- **首开中老年班（56-70 岁）50 门课，拟招 1300 人 → 实际仅 600 名中老年成功报名。** 官方归因："**老年人对线上操作不熟练**……咨询电话大都是老年人打来的，询问如何报名。"
- 官方点名的结构性缺口：**"56-60 岁两不靠"**（超过夜校原 18-55 岁范围，老年大学白天开班又参与不了）。
- 官方承认："**热门课程'秒光'与基础课程闲置并存**" → R13 有真实可捡漏库存。

**⚠️ 红线**：R12 **只做提醒、图文指引、信息预填，绝不实现自动化抢课脚本**。前者是助老工具，后者是黄牛行为，会导致产品被官方封禁并丧失合作可能。

### 修正 3 · 用户故事与人群分阶段
- **移出 MVP**：用户故事 2「张叔·老漂」→ 降级到 **M3**。上海数据显示老漂族 **20%+ 未受任何教育、近 50% 小学文化、56.3% 宁可待室内**，线上产品无法自增长，必须靠居委/社工/"老漂驿站"线下带（可借力：松江方松街道上泰绅苑、浦东金杨新村街道东方知音苑现有老漂驿站）。
- **新增 MVP 主故事**：

### 修正 4 · 试点城区（原第 148 行行动项已闭环）

## 🔧 M0 二次修正（模型修正 · 2026-09-01 末）

> 依据：用户最新指令——"上海作试点即可；零人力采集、零烧钱，全 AI agent 爬取分析汇总；用户按定位查附近 3/5km 活动"。以下**取代/补充** M0 修正记录相关项。

### 修正 A · 试点范围：上海全市（不再限定 1-2 街道）
- 自动化采集下，AI agent 可覆盖全市结构化供给，无需人工蹲点街道。原 修正4 的"曲阳路/古美路"保留为**首批优先种子区域**（供给密度最高），范围扩展到全市。

### 修正 B · 运营模型：零人力 · 零烧钱 · 全自动数据管道
- 原 M0 行动项"人工采集 2 周活动""访谈 5-8 人"作废。
- 新管道（全 AI-agent）：
  1. **抓取 crawl**：定时爬取上海结构化活动源——文化云、各区文旅局/街镇官网、上海老年大学、市民艺术夜校、群艺馆。
  2. **解析 parse**：抽取 活动名 / 时间 / 地点文本 / 主办方 / 报名方式+链接 / 费用 / 适龄。
  3. **地理编码 geocode**：地点文本 → 经纬度（**关键步骤**，决定能否按半径查询）。
  4. **服务 serve**：按用户 GPS + 选定半径（默认 3km / 可选 5km / 10km）返回本周活动，按距离+时间排序。
- 成本：serverless + 地图免费额度 + 轻量爬虫，月成本几十元级（近零烧钱）。

### 修正 C · MVP 核心换位：LBS 半径发现成为第一入口
- **原 MVP 中心**：周历 Feed（R1）。
- **改为**：**"附近 3/5km 本周活动"** 为小程序首屏主入口，周历退为其中一个排序视图。
- 新需求 **R14（P0，置于最前）**：基于定位的半径发现（3/5/10km 切换、按距离+时间排序、大字卡）。
- 原 R11/R12/R13（开抢日历/报名助手/捡漏）**降为 P1**：仍保留为差异化增值（老同志确实抢不到），但不再是 MVP 尖刀。

### 修正 D · 与 文化云 的差异化重新表述

- 但本指令补上两个变量使其重新锋利：
  - **① 零成本全自动**（无人工运营，可长期免费维持）；
