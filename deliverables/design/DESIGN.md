# old-buddy 适老化设计系统与页面规格

**版本** v1.0 · 2026-09-02
**设计师** 颜好看（UI/UX）
**平台** 微信小程序（单一目标平台，不做 H5 自适应双栈）
**产品定位**（承接 PRD 修正 C）你家门口本周活动雷达 —— 打开即按定位看"附近 N 公里本周有啥"
**目标用户** 50-60 岁上海城市退休族，带孙间隙有大段空闲，怕复杂操作、怕诈骗、不愿麻烦子女

## 0. 设计前置决策（后续所有取舍的依据）

### 0.1 设计寄存器：Product（产品型）

设计服务于产品，不是设计本身。标杆是"赢得熟悉感"——用户第一眼就知道这是个正经、稳当、能信的东西，而不是被设计惊艳。
落地含义：中性色主导（占表面 85% 以上），单一强调色承载"可点击"语义，零装饰性动效，零摄影大图 Hero，信息密度低但层级极硬。

### 0.2 三轴刻度标定

| 轴 | 取值 | 理由 |
|---|---|---|
| DESIGN_VARIANCE | **3 / 10** | 适老化的第一性原理是**可预测**。同类元素必须长得一样、在同一位置、用同一手势。非对称布局、错落网格、视差全部禁用 |
| MOTION_INTENSITY | **2 / 10** | 老年人对运动物体追踪能力下降，动效只用于"状态确认"与"空间连续"，不做愉悦时刻 |
| VISUAL_DENSITY | **2 / 10** | 一屏 2.5 张卡片是上限。宁可多滚一屏，不可挤成一堆 |

低 VARIANCE 的风险是"相同卡片无限重复"（AI 模板第 5 罪）。解法不是打乱布局，而是**用真实数据制造节奏**：今天/明天开始的活动卡强化、半径统计条、免费与收费视觉分流。详见 §5.4。

### 0.3 显式偏离设计基线的三处声明

适老化对通用规范做了三处受控上调，全项目统一执行，不得混用：

| 项 | 通用基线 | 本项目 | 依据 |
|---|---|---|---|
| 图标尺寸档位 | 16 / 20 / 24 px | **20 / 24 / 28 px** | 16px 线性图标在 50-60 岁人群（对比敏感度下降）下辨识失败率高。整体上移一档 |
| 触摸目标 | ≥44×44 px | **≥48×48 px**，主操作 ≥56 px 高 | 手指精细动作退化 + 常在户外/单手带孩子操作 |
| 强调色可见处 | 每屏 ≤2 处 | **每屏 ≤3 处** | 主色是"可点击"的唯一信号，需覆盖主按钮 + Tab 选中 + 分段控件选中；超过 3 处仍视为噪音 |

## A. 设计 Token

Token 分四层：**A1**（品牌核心，必须声明）/ **A2**（有默认值）/ **B-slot**（别名）/ **C-ext**（项目专属）。
小程序中所有 Token 定义在 `app.wxss` 的 `page` 选择器上（小程序无 `:root`），组件内一律 `var()` 引用。**除 `#fff` 外禁止任何裸色值进组件样式。**

### A.1 色彩

#### 为什么是这套色：50-60 岁视觉的三个硬约束

1. **晶状体黄化** —— 短波光（蓝、紫、蓝绿）透过率随年龄下降，中等明度的蓝在老年人眼里发灰发暗。因此主色**不靠色相取胜，靠明度差取胜**：主色做到足够深，永远以"深色块 + 白字"或"白底 + 深色字"出现，对比比 8:1 以上，色相退化不影响可读性。
2. **对比敏感度下降** —— 灰叠灰、1.5:1 的分隔线在老年人眼里等于不存在。因此结构边框做到对相邻面 **3:1 以上**（WCAG 1.4.11），线是"看得见的线"。
3. **眩光敏感度上升 + 瞳孔缩小** —— 大面积纯白 `#FFFFFF` 满屏会眩光，同时进光量比年轻人少约 1/3。因此页面底色用极浅冷灰 `#F4F6F8`（不是奶油色/米色，避开暖中性带），卡片用纯白浮在上面，卡片边界因此天然可辨。

主色 **墨青蓝 #0B4F6C**（Harbor Ink）：上海海港的深青蓝，社区/公共服务语境中读作"官方、稳、可托付"，且不是 Tailwind 默认靛蓝，不是任何 AI 模板色。
辅色 **赭橙 #B23A0E**（Alert Amber-Red）：长波暖色，是老年人辨色能力保留最完整的区间，专用于"时间紧迫"（今天开始 / 即将开抢）。

#### A1-identity

| Token | 值 | 用途 | 对比比 |
|---|---|---|---|
| `--bg` | `#F4F6F8` | 页面底色（冷极浅灰，防眩光） | — |
| `--surface` | `#FFFFFF` | 卡片 / 弹层 / 输入框 | — |
| `--fg` | `#16202A` | 主文本（近黑带蓝调，非纯黑） | 16.5:1 on surface |
| `--muted` | `#5A6875` | 三级元数据，**仅允许 ≥16px** | 5.7:1 |
| `--accent` | `#0B4F6C` | 主色，"可点击"唯一信号 | 8.9:1 |
| `--border` | `#7C8A96` | 结构边框（卡片外框 / 输入框 / 分段轨道） | 3.3:1 on bg |
| `--font-display` | `"PingFang SC", "HarmonyOS Sans SC", "Source Han Sans SC", "Microsoft YaHei", sans-serif` + `600` | 标题 | — |
| `--font-body` | 同上字体栈 + `400` | 正文 | — |

#### A2（语义色 —— 全部满足 4.5:1 以上，且禁止单独承载信息）

| Token | 值 | 用途 | 对白字 |
|---|---|---|---|
| `--accent-on` | `#FFFFFF` | 主色块上的前景 | — |
| `--accent-pressed` | `#083B51` | 按下态（仅变色，不变形） | — |
| `--accent-wash` | `#E7EFF3` | 主色浅底（选中项底、信息条底） | 承载 `--accent` 文字 7.5:1 |
| `--success` | `#146B3A` | 免费 / 已收藏 / 官方已核验 | 6.6:1 |
| `--success-wash` | `#E4F0E9` | 免费标签底 | — |
| `--warn` | `#8A5200` | 需付费 / 数据待核实 / 防骗提示 | 6.3:1 |
| `--warn-wash` | `#FBF0DE` | 防骗提示条底 | — |
| `--danger` | `#B3261E` | 报错 / 举报 / 取消收藏确认 | 6.6:1 |
| `--urgent` | `#B23A0E` | 辅色：今天 / 即将开始 | 6.0:1 |
| `--font-num` | `"SF Pro Text", "DIN Alternate", var(--font-body)` + `font-variant-numeric: tabular-nums` | 距离 / 时间 / 金额等宽对齐 | — |

**语义色使用铁律**：颜色只是第三重编码。任何状态必须同时满足 **图标 + 文字 + 颜色** 三重表达。
例：免费 = `payments` 图标 + 文字"免费" + `--success-wash` 底。绝不允许"绿色圆点=免费、橙色圆点=收费"这种纯色编码（老年人蓝黄/红绿辨识均退化）。

#### B-slot（别名，可被页面级覆盖）

| Token | 默认指向 | 用途 |
|---|---|---|
| `--fg-2` | `#33414F` | 次级文本（卡片副信息、正文），10.3:1 |
| `--surface-2` | `#E8EDF1` | 三级面：分段控件轨道、禁用底、骨架屏块 |
| `--border-soft` | `#DCE3E9` | 卡片内部行分隔（不承载信息，允许低对比） |
| `--icon-color` | `var(--fg-2)` | 图标默认色（SVG mask 换色用） |

#### 禁止色（出现即退回）

- 任何 `#7C3AED` `#A855F7` `#9333EA` `#EC4899` 之间的渐变组合
- Tailwind 默认靛蓝 `#6366F1` / `#4F46E5` 作为强调色
- 纯黑 `#000000` 作为文本、纯灰 `#808080` 作为任何用途
- 暖中性背景带（奶油/米色/沙色，OKLCH L 0.84-0.97 / C<0.06 / hue 40-100）
- 半透明毛玻璃背景上放文字（老年人识别失败）

### A.2 字体与字号阶梯

#### 字体决策：为什么不加载品牌字体

中文字库单字重 5-10MB，小程序包体上限 2MB / 分包 20MB，`wx.loadFontFace` 在部分安卓机型对已渲染节点不生效且首屏闪白。**加载中文 Web Font 在本项目是错误工程决策**。
替代方案是把"品牌字体组合"落在**字体栈 + 字重 + 字距 + 层级**四件套上，明确锁定：

| 角色 | Token | 字体栈 | 字重 |
|---|---|---|---|
| Display（标题） | `--font-display` | PingFang SC → HarmonyOS Sans SC → Source Han Sans SC → Microsoft YaHei | 600 |
| Body（正文） | `--font-body` | 同上 | 400 |
| Numeric（数字） | `--font-num` | SF Pro Text / DIN Alternate + `tabular-nums` | 500 |

**安卓字重漂移防护**：部分安卓 ROM 无 600 字重，会回落成 400，导致标题与正文糊成一片。因此**层级不得只靠字重传达**，必须"字号差 ≥4px + 颜色差（`--fg` vs `--fg-2`）+ 位置"三重编码。

**数字用等宽（tabular-nums）**：列表里"0.6 公里 / 1.2 公里 / 12 公里"数字位对齐，老年人纵向扫读速度显著提升。

#### 字号阶梯：px 而非 rpx

**关键决策：字号与触摸目标一律用 px，禁止 rpx。** 理由：`rpx` 按 750 设计稿等比缩放，在 320px 宽机型上 1rpx = 0.427px，18px 字会被压到 15.4px，适老化下限被击穿。仅容器宽度、横向间隙允许用 `%` / `flex`。

基础字号 **18px 起**，三档大字模式（`page` 根节点挂 `data-fontscale`）：

| Token | 标准 1.0 | 大 1.15 | 特大 1.3 | 用途 |
|---|---|---|---|---|
| `--text-xs` | 14 | 16 | 18 | 仅徽章内文字，**禁止用于正文** |
| `--text-sm` | 16 | 18 | 21 | 元数据、字段 label（最小允许字号） |
| `--text-base` | **18** | 21 | 23 | 正文基准 |
| `--text-md` | 20 | 23 | 26 | 卡片副信息、列表项、按钮文字 |
| `--text-lg` | 22 | 25 | 29 | 卡片标题 |
| `--text-xl` | 26 | 30 | 34 | 页面区块标题、页内大标题 |
| `--text-2xl` | 30 | 34 | 39 | 详情页活动名 |
| `--text-3xl` | 34 | 39 | 44 | 半径统计强调数字 |

**初始档位自动匹配**：首次进入读 `wx.getSystemInfoSync().fontSizeSetting`（微信内"字体大小"设置值），≥18 自动切"大"档，≥22 自动切"特大"档，并在"我的-设置"里可手动覆盖。用户已在微信里放大过字体，说明他需要大字——不该让他再设一遍。

#### 行高与字距

| Token | 值 | 适用 |
|---|---|---|
| `--leading-body` | 1.75 | 正文（比通用 1.5 上调，老年人需要更大行距定位行首） |
| `--leading-tight` | 1.35 | 卡片标题、列表项 |
| `--leading-display` | 1.2 | `--text-2xl` 及以上 |
| `--tracking-cjk` | 0.01em | 中文正文（微增字距提升单字辨识） |
| `--tracking-display` | 0 | 中文标题不用负字距（会让笔画粘连） |

**排版禁令**：正文行宽 ≤ 22 个汉字（375px 屏 - 40px 边距 = 335px，18px 字约 18 字/行，达标）；卡片标题最多 2 行后省略号，完整标题在详情页；**禁止任何文本使用 `--text-xs` 以下字号**。

### A.3 间距（4px 网格）

仅允许下列值，禁止 `5 / 7 / 13 / 15 / 18 / 22 / 30`：

| Token | 值 | 典型用途 |
|---|---|---|
| `--space-1` | 4 | 图标与紧邻文字 |
| `--space-2` | 8 | 徽章内边距、标签内边距 |
| `--space-3` | 12 | 卡片内行间距 |
| `--space-4` | 16 | 卡片之间的间距、小屏页面横向边距 |
| `--space-5` | 20 | **卡片内边距、页面横向边距（标准）** |
| `--space-6` | 24 | 卡片内区块分隔 |
| `--space-8` | 32 | 页面区块之间 |
| `--space-10` | 40 | 首屏顶部区与内容区之间 |
| `--space-12` | 48 | 空状态上下留白 |
| `--space-16` | 64 | 列表末尾吸底栏避让 |

节区节奏：小程序单列，纵向区块间距统一 `--space-8`（32px）。
安全区：底部一律 `padding-bottom: calc(X + env(safe-area-inset-bottom))`；首页自定义顶栏一律 `padding-top: env(safe-area-inset-top)`。

### A.4 圆角

| Token | 值 | 用途 |
|---|---|---|
| `--radius-sm` | 10 | 输入框、类型标签、徽章 |
| `--radius-md` | 14 | **卡片、按钮（主形状语言）** |
| `--radius-lg` | 18 | 半屏弹层顶部两角、大图片 |
| `--radius-pill` | 9999 | 分段控件滑块、免费标签、筛选 chip |

卡片圆角上限 16px。禁止 ≥24px 的过度圆角（读作玩具感，与"可托付"定位冲突）。

### A.5 阴影（边框与阴影互斥）

| Token | 值 | 用途 |
|---|---|---|
| `--elev-flat` | `none` | 默认卡片：`1px solid var(--border)` + 无阴影 |
| `--elev-raised` | `0 2px 8px rgba(11,79,108,0.10)` | 吸底操作栏、自定义 Tab 栏（**无边框**） |
| `--elev-sheet` | `0 -4px 20px rgba(22,32,42,0.16)` | 半屏弹层向上投影（**无边框**） |

**铁律**：同一元素禁止同时出现 `1px 边框` 与 `blur ≥ 16px` 的阴影（幽灵卡片）。适老化下卡片靠"白底 + 可见边框"区分，不靠柔和阴影——老年人看不见柔和阴影。

### A.6 动效（禁止弹跳/弹性）

| Token | 值 | 用途 |
|---|---|---|
| `--motion-fast` | 120ms | 按下反馈（颜色变化） |
| `--motion-base` | 180ms | 状态切换、分段控件滑块、标签选中 |
| `--motion-sheet` | 240ms | 半屏弹层升起 / 落下 |
| `--ease-standard` | `cubic-bezier(0.2, 0, 0, 1)` | 进入 / 位移 |
| `--ease-linear` | `linear` | 进度条、骨架屏呼吸 |

**禁止**：任何带 overshoot 的缓动（`cubic-bezier` 含负值或 >1 的 y 值）、spring / bounce / elastic / back 曲线、`scale` 弹跳按下态、自动轮播、闪烁频率 >3Hz 的动画。
**按下反馈只做颜色**：`--accent` → `--accent-pressed`，不做位移、不做缩放。老年人手抖时位移反馈会被误读为"点错了"。
**减少动画**：小程序对 `prefers-reduced-motion` 支持不稳定，因此在"我的-设置"提供**减少动画**开关，根节点挂 `data-motion="reduced"` 时全部 `transition-duration: 0.01ms`，骨架屏呼吸改为静态灰块。

### A.7 组件规格

#### 按钮（4 型）

| 型 | 高 | 背景 | 文字 | 圆角 | 字号/字重 | 场景 |
|---|---|---|---|---|---|---|
| Primary | **56** | `--accent` | `--accent-on` | `--radius-md` | `--text-md` / 600 | 一屏唯一主操作（去报名、看详情、允许定位） |
| Secondary | **56** | `--surface` + `1.5px solid --accent` | `--accent` | `--radius-md` | `--text-md` / 600 | 并列次操作（手动选街道、我再想想） |
| Text | 48 | 透明 | `--accent` | — | `--text-md` / 400 + 下划线 | 弱操作（换个位置、举报） |
| Icon | **48×48** 触摸区 | 透明 / `--surface` | 图标 24px | `--radius-pill` | — | 收藏、分享、关闭 |

Icon 型**必须**配 `aria-label`；单独出现时旁边必须有文字说明（禁止纯图标导航）。

#### 按钮状态矩阵（9 态）

小程序无 `hover` / `focus-visible`，映射如下：

| 状态 | 实现 | 视觉 |
|---|---|---|
| Default | — | 基线 |
| Pressed | `hover-class` + `hover-start-time="0"` `hover-stay-time="120"` | 背景 → `--accent-pressed`，仅变色 |
| Focus（读屏） | `aria-label` + `role="button"` + `tabindex` | 系统焦点框，禁止移除 |
| Disabled | `disabled` | 背景 `--surface-2`，文字 `--muted`，**同时显示原因文字**（不留用户猜） |
| Loading | 按钮内替换为 24px 旋转环 + 文字"正在打开…" | 宽度锁定不跳动 |
| Error | 按钮下方 inline 错误行（`error` 图标 + `--danger` 文字 + 重试按钮） | 不用 Toast 单独承载 |
| Empty | 见 §6 各页空态 | — |
| Success | inline 状态变更（如心形填充 + 文字"已收藏"）+ 3.5s Toast | Toast 时长 ≥3.5s |
| Edge | 文字超长时按钮不换行、内容单行省略，最小宽度 96px | — |

#### 卡片

- 背景 `--surface`，`1px solid var(--border)`，`--radius-md`，内边距 `--space-5`（20px），阴影 `--elev-flat`
- 整卡可点（触摸区即整卡，非仅标题）；按下时整卡背景 → `--accent-wash`，120ms
- 卡内不使用彩色左边框（AI 模板第 5 罪）。强调靠**顶部 4px 色带**（仅"今天/明天"卡使用 `--urgent`）
- 卡内分隔线用 `--border-soft` 1px

#### 类型标签（Type Chip）

pill 形，高 32，内边距 `0 --space-3`，`--text-sm`，**图标 20px + 文字**同时存在。
浅底深字，每类一色但全部满足 4.5:1；颜色仅作辅助，语义由图标与文字承载。

| 类型（对齐 `type` 字段） | 底 / 字 |
|---|---|
| 文艺（书法·合唱·舞蹈·演出） | `--accent-wash` / `--accent` |
| 学习（讲座·课堂·手机课） | `#EDE9E2` / `#6B4A17` |
| 健康（太极·健身·义诊） | `--success-wash` / `--success` |
| 公益（志愿·义工） | `#EAE7F2` / `#3D3A66`（纯色，非渐变） |

#### 底部 Tab（必须用自定义 tabBar）

**原生 tabBar 文字大小固定约 10px 且不可调，适老化下不可接受**，因此必须使用 `custom-tab-bar`。

- 高 **64px** + `env(safe-area-inset-bottom)`，背景 `--surface`，`--elev-raised`，无上边框
- 3 个 Tab（认知负荷 ≤4）：附近 / 分类 / 我的
- 每 Tab 触摸区 = 屏宽/3 × 64px（远超 48px）
- 图标 **28px**，文字 `--text-xs`（14px，特大档 18px，Tab 高度随之升到 76px）
- 选中态三重编码：图标 `FILL 1` 填充 + 文字 600 + 色变 `--accent` + 整格 `--accent-wash` 圆角底（`--radius-md`）
- 未选中：`--muted`，图标 `FILL 0`
- 禁止小红点数字角标（老年人读作"出错了"），有新内容用文字"有 3 场新的"

#### 弹层（半屏 Sheet）

- 从底部升起，`--motion-sheet` 240ms，`--ease-standard`，**不带回弹**
- 顶部两角 `--radius-lg`，`--elev-sheet`，遮罩 `rgba(22,32,42,0.45)`（足够深，老年人能识别"后面那层被挡住了"）
- 顶部 48px 标题区：标题 `--text-xl` 左对齐 + 右上 `close` 图标按钮 48×48
- 主操作吸底，`--space-5` 内边距 + safe-area
- 高度上限 76vh，内容超出可滚；**禁止用手势下拉关闭作为唯一关闭方式**，关闭按钮必须常驻
- 场景：换位置 / 半径选择 / 报名外跳确认 / 取消收藏确认

#### 开关（自定义，禁用原生 switch）

原生 `switch` 约 52×32，且状态仅靠颜色+滑块位置传达——老年人识别失败率高。自定义规格：

- 尺寸 **72×40**，圆角 pill，触摸区扩展到 48px 高
- 关：底 `--surface-2`，滑块白色在左，**轨道右侧显示"关"字**（`--text-xs`，`--muted`）
- 开：底 `--accent`，滑块白色在右，**轨道左侧显示"开"字**（`--text-xs`，`--accent-on`）
- 切换 180ms 线性位移，无弹跳
- 开关左侧必须有文字标签 + 一行说明（如"语音播报 / 打开后，点‘听一听’会读给你听"）

#### 输入框（仅搜索页使用）

高 56，`--radius-sm`，`1.5px solid var(--border)`，字号 `--text-md`，聚焦时边框 → `--accent` 2px。
**Label 必须可见**，禁止用 placeholder 充当 label。

| 组件 | 行为 |
|---|---|

## C. 图标清单

### C.1 锁定图标库：Material Symbols Outlined

**变体轴全局锁定**：`FILL 0` · `wght 500` · `GRAD 0` · `opsz 24`

选它的四个理由：
1. **可变字重轴**是适老化的决定性优势 —— 把描边从默认 wght 400 加到 500，24px 下视觉描边约 2.2px，比 Lucide 固定 2px 更实心可辨（对比敏感度下降的人群需要更粗的线）
2. **FILL 轴做选中态** —— 收藏心形、Tab 选中只切 `FILL 0/1`，无需两套图标，形状绝对一致
3. 语义覆盖完整，本项目所需 `near_me` / `directions` / `verified_user` / `self_improvement` 等全部有官方图标
4. Apache 2.0，可商用

**尺寸档位（全项目仅此三档）**：`20px` 行内 / `24px` 按钮内与列表项 / `28px` Tab 与独立入口。

**小程序集成方式**：把用到的图标导出为单色 SVG → 转 CSS `mask-image` data-uri，颜色由 `--icon-color` 或 `background-color` 控制。
**禁止使用 iconfont 字体方案** —— `@font-face` 图标在部分安卓 ROM 上出现基线错位与首屏方块。
**禁止混入任何其他图标库**，禁止 emoji 作为功能图标（emoji 在不同机型渲染差异大，且老年人常读不出语义）。

## D. 适老化专项落点

### D.1 大字号

| 落点 | 做法 |
|---|---|
| 基础字号 | 正文 18px 起，最小允许 16px（仅字段 label 与徽章），14px 仅限徽章内 |
| 三档缩放 | 标准 1.0 / 大 1.15 / 特大 1.3，根节点 `data-fontscale` 切换，全部通过 Token 覆盖，页面代码零改动 |
| 初始档自动匹配 | 读 `wx.getSystemInfoSync().fontSizeSetting`，≥18 自动"大"档、≥22 自动"特大"档 |
| 入口可发现性 | 设置项放"我的"页第一个区块首位，带**实时预览句**（改档位整页立即变，不需要返回验证） |
| 布局抗放大（关键） | 特大档下：卡片元数据行由横排改纵排；Tab 高 64→76、文字 14→18；按钮文字不换行、按钮改通栏；所有容器 `min-height` 不写死，改 `padding` 撑开 |
| 溢出兜底 | 卡片标题 2 行截断（详情页完整）；`--text-2xl` 以上标题允许换行不截断；禁止任何 `overflow: hidden` 吞掉关键信息 |

### D.2 高对比

| 落点 | 指标 |
|---|---|
| 主文本 | `--fg` on `--surface` = **16.5:1**（远超 AAA 7:1） |
| 次级文本 | `--fg-2` = **10.3:1** |
| 三级元数据 | `--muted` = **5.7:1**，且限定 ≥16px、不承载关键信息 |
| 主色文字/色块 | `--accent` = **8.9:1** |
| 语义色 | success 6.6 / warn 6.3 / danger 6.6 / urgent 6.0，全部 ≥4.5:1 |
| 结构边框 | `--border` 对 `--bg` = **3.3:1**，满足 WCAG 1.4.11 非文本对比 |
| 防眩光 | 页面底 `#F4F6F8` 而非纯白满屏；禁止大面积高饱和色块 |
| 禁止项 | 灰叠灰、半透明文字、毛玻璃上放文字、`opacity < 0.7` 的文本、纯色编码状态 |

### D.4 语音播报

三级落点，逐级加深：

| 层级 | 位置 | 播报内容 |
|---|---|---|
| 卡片级 | 每张活动卡"听一听"（Secondary 48px） | 结构化模板：「{title}。{时间文案}。在{venue}，离你{距离文案}，走路约{N}分钟。{费用}。」 |
| 详情级 | 顶部"读给我听"通栏（56px） | 活动名 + 五个字段 + 活动介绍全文 + 防骗提示 |
| 长文级 | 防骗须知页 / 关于页顶部 | 全文朗读 |

**播报中状态设计**（必须让老年人知道"在读了、怎么停"）：
- 触发的按钮就地变为 `pause` + 文字"正在读…点这里停"
- 当前朗读卡片左侧出现 3px `--accent` 竖条标识
- 全局同时只允许一个播报源；开始新的自动停止旧的
- 播报结束按钮自动恢复，无需用户操作
- 失败降级：TTS 失败显示"暂时读不出来，网络不太好"+ `refresh` 重试，**不静默失败**

**开关与默认值**：设置页"语音播报"总开关，默认**关**（避免公共场合突然出声吓到用户），首次进入详情页用一次性提示卡引导"想让它读给你听吗"。开启后进入详情页自动朗读标题+时间（可在设置里单独关闭自动朗读）。

**给前端的接口需求**：活动对象需增加 `tts_text`（后端按上述模板生成的朗读文本）与可选 `tts_url`（云端 TTS 生成的 mp3）。前端 `wx.createInnerAudioContext` 播放；无 `tts_url` 时前端可用 `tts_text` 走云端合成。微信无内置 TTS API，必须服务端提供。

**读屏无障碍（与语音播报并行，不可互相替代）**：所有图标按钮带 `aria-label`；卡片带 `role="button"` 与聚合 `aria-label`（同 `tts_text`）；装饰性元素 `aria-hidden="true"`；确保 iOS VoiceOver / 安卓 TalkBack 可完整走通"定位 → 半径 → 卡片 → 详情 → 报名"主流程。

### D.5 防诈骗视觉体系

五个落点构成闭环，每个都有具体视觉载体：

| 落点 | 视觉 | 位置 |
|---|---|---|
| **1. 溯源可见** | `verified_user` + `--success-wash` 条："来自 上海市公共数据开放平台 · 9 月 1 日更新"。未核实源降级为 `info` + `--warn-wash`："这条还没核实，去之前请打电话确认" | 详情页顶部（第一眼位置）；卡片右下角 16px 小徽标 |
| **2. 费用明示** | 免费 → `--success-wash` pill"免费"；收费 → `--warn` 文字"¥80（主办方收取）"；两者都跟一句"old-buddy 不代收任何费用" | 卡片 + 详情费用字段 |
| **3. 外跳拦截** | 半屏弹层展示**真实域名 + 平台中文名**（等宽字体、`--accent-wash` 底），配"我再想想"退路 | 点报名按钮时 |
| **4. 常驻教育** | `--warn-wash` 条 + `shield`："记住三句话：不转账 · 不垫付 · 不买卡"，点进防骗须知 | 首页每 6 张卡插一次；我的页；详情页报名区上方 |
| **5. 举报通路** | `--danger` Text 按钮"这个活动有问题，我要举报"，两步提交（选原因 + 可选补充），提交后明确回执"收到了，我们会去核实" | 详情页防骗条内 + 我的页底部 |

**防骗设计的三条原则**：
1. **不制造恐慌** —— 用 `--warn`（琥珀）不用 `--danger`（红）承载常规提示；红色只留给真实错误与举报
2. **给出可执行动作** —— 每条提示都跟一个动作（打电话核实 / 问子女 / 举报），不是空泛"请注意安全"
3. **说人话** —— "凡是要你转账、垫付、买保健品的都是骗子"，不写"请警惕非法金融活动"

## F. Do / Don't

### 允许（Do）

- 同类元素在所有页面**完全同构**（活动卡只有一套设计）
- 每屏只有一个主操作（Primary 按钮全屏唯一）
- 所有状态"图标 + 文字 + 颜色"三重编码
- 空态给出带真实数字的可执行下一步（"放大到 3 公里，有 8 场"）
- 距离/时间用生活语言（"600 米 · 走路约 9 分钟"、"今天 14:00"）
- 数字用等宽字体纵向对齐
- 导航一律交给微信内置地图（`wx.openLocation`）
- 关键结果用 inline 状态变更，Toast 只作补充且时长 ≥3.5s

### 禁止（Don't）

- emoji 作为功能图标（含 `checkmark` 类符号字符）；混用第二套图标库
- 紫→粉渐变、Tailwind 默认靛蓝作强调色、任何裸色值进组件样式
- 弹跳 / 弹性 / spring / 回弹缓动；按下态做 `scale` 或位移；自动轮播
- 毛玻璃、半透明背景上放文字
- 卡片彩色左边框；卡片圆角 ≥24px；`1px 边框 + blur≥16px` 同元素并存
- 纯图标按钮、纯色状态编码、placeholder 充当 label
- 左滑删除 / 长按菜单作为唯一操作路径；滚轮 picker
- 自绘地图、渲染行政边界、展示自有地图瓦片
- 小红点数字角标（读作报错）；全屏遮罩引导；强制注册才能浏览
- 空洞文案："欢迎使用"、"暂无数据"、"敬请期待"、"精彩活动等你发现"

## H. 给前端工程师的实现提示

1. **Token 先落地**：`app.wxss` 里 `page{}` 定义全部变量 + 三套 `[data-fontscale]` 覆盖块 + 一套 `[data-motion="reduced"]` 覆盖块。同时引入 `design-tokens.json` 作为唯一色值来源（JS 侧需要色值时从此 import，不要抄写）。
2. **必须自定义 tabBar**（`custom-tab-bar/`），原生 tabBar 文字 10px 不可调，适老化直接不合格。
3. **首页 `navigationStyle: custom`，其余页保留原生导航栏**——返回一致性优先于视觉统一。
4. **字号与触摸尺寸一律 px，禁止 rpx**；仅容器宽度、横向间隙用 `%` / `flex`。
5. **活动卡只写一个组件**（`components/activity-card`），首页/分类/收藏三处复用，禁止各写一份。
6. **图标组件化**：`components/ms-icon`，props 为 `name` / `size`(20|24|28) / `color` / `fill`(0|1)，内部走 CSS `mask-image`。只允许这三个尺寸值。
7. **按下反馈全用 `hover-class`** + `hover-start-time="0"` `hover-stay-time="120"`，只改背景色。
8. **无障碍属性不是可选项**：所有可点元素 `aria-label` + `role`，卡片聚合 label 复用 `tts_text`。
9. **定位授权走"用时申请"**：不在启动时请求，在用户首次需要距离时请求，并先用自有说明页解释"只看一次、不保存"，再调 `wx.getLocation`（PRD 修正 E 隐私要求）。
10. **禁止在 WXSS 里写任何裸色值**（`#fff` 除外）。CI 建议加一条正则门禁：`#(?!fff\b)[0-9a-fA-F]{3,8}` 命中即失败。
